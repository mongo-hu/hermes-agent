# 注塑 DFM 需求与覆盖台账

状态：需求基线，不代表已实现能力。更新：2026-10-19。[开发导航](README.md)

本台账是 19 类、171 条来源需求及其覆盖边界和任务关联的唯一逐行维护位置。它合并工程清单、覆盖矩阵、分类评审及任务文档的追溯索引；原始编号、逐行工程描述、覆盖边界与任务关联已经核对保留，重复清单不再另存仓库；分类依据见[历史评审归档](archive/2026-10-19/README.md)。

## 使用口径

- 来源编号如 01.09 不是 check_id；171 行不是 171 个独立算法。同一业务可有多个来源行，不能因此重复测量或重复计问题。
- A/B/C/D 表示方案路径和输入边界，不是严重程度，也不是当前完成状态。实际可执行范围由已发布规则、能力和本次输入决定。
- 原清单中的经验数值是工程需求资料，不写死进程序，不覆盖已发布规则；实际阈值、适用条件及公式以审核后的 Rule Version 为准。
- 启动时登记模型、工艺和单位，确认主方向；主方向未知不猜测，结构识别及不依赖方向的量可先推进。材料等业务 Fact 按适用规则补充，局部方向按组提供。
- 产品用途、外观、纹理及工程对象需可靠来源和用户确认；型芯／型腔侧候选不是实际模具实体。物理仿真和试模结论不能由几何预筛替代。
- 具体运行顺序见[主流程](dfm-main-workflow-explained.md)，会话、coverage 和依赖处理见[会话设计](dfm-geometric-session-contract.md)；本台账不重复定义协议。

| 路径 | 来源行数 | 能判断到什么程度 | 必须补齐什么 |

| A 主流程可判 | 44 | 产品结构、几何量与明确规则 | 对应算法、必要属性、方向和对象确认 |
| B 补对象可判 | 70 | 补齐后继续使用几何与规则流程 | 模具／装配／机构／工具、标注、PMI 等结构化对象 |
| C 仅预筛 | 39 | 几何风险代理量可判规则，不代表物理结果 | 仿真、工艺验证或试模依据 |

分类不强制排他。例如 D 类材料认证可能需要 A 类壁厚，但不能因此把材料认证变成纯几何结论。宽泛议题应拆成几何预筛与物理／实测验证 Check，报告保留各自覆盖程度。

## 计算口径与责任边界

厚度需对向面、材料内有效路径和明确采样口径，不能直接取所有面的最短距离；装配净距允许真实接触为零。筋／柱的参考厚度是局部关联主壁，不是全件平均值。拔模必须使用对应成型方向及统一符号，负角本身不等于真实倒扣。深径比区分有效成型段、锥底和阶梯段；钢料分析先明确模具材料域。极值和未检出结论要附覆盖与精度限制。

下表 G0—G12 仅是能力分组标签，不是对外 geometric_id，不建立另一套路由 ID。具体 G 定义在[Feature—Check—G 映射](%E6%B3%A8%E5%A1%91%E4%BB%B6%20DFM%20A%E7%B1%BB%E7%89%B9%E5%BE%81%E5%8C%BA%E5%9F%9F%E4%B8%8E%20Check-Geometric%20%E6%98%A0%E5%B0%84%20V1.0.md)，交付与验收在[任务清单](%E6%B3%A8%E5%A1%91%E4%BB%B6%20DFM%20%E7%89%B9%E5%BE%81%E8%AF%86%E5%88%AB%E4%B8%8E%E5%87%A0%E4%BD%95%E8%AE%A1%E7%AE%97%E5%BC%80%E5%8F%91%E4%BB%BB%E5%8A%A1%E6%B8%85%E5%8D%95%20V1.0.md)。
