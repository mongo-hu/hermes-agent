# 注塑 DFM 需求与覆盖台账

状态：需求基线，不代表已实现能力。更新：2026-11-05。[开发导航](README.md)

本台账维护注塑 DFM 范围内的 19 类、146 条来源需求、覆盖边界及任务关联。原始需求基线共 171 条，本次移除 25 条超出范围的需求，并收敛混合条目的判定目标；保留原来源编号，编号空缺不补排。历史范围与分类依据见[历史评审归档](archive/2026-10-19/README.md)。

## 范围

本台账的 DFM 指注塑产品及其模具的可制造性：能否在给定材料、设备和工艺条件下完成成型、脱模，并满足约定的制造尺寸与成型外观要求。

| 范围 | 本台账的处理 |
| --- | --- |
| 产品几何与成型 | 保留壁厚、厚肉、流动充填、排气、冷却、收缩翘曲、拔模、倒扣和顶出风险 |
| 模具实现 | 保留钢料、型芯、机构运动、加工可达性，以及影响生产和修模的拆装、清理空间；模具装配是制造实施条件 |
| 制造质量与工艺 | 保留图纸／PMI 所要求尺寸的制造能力、成型表面质量、材料加工窗口，以及嵌件注塑和包胶成型 |
| 产品装配（DFA） | 不纳入配合间隙、螺钉啮合、装配路径、装配防错和产品装配公差链 |
| 产品使用性能 | 不纳入服役承载、刚度、抗扭／拉拔、卡扣弹性行程与疲劳、功能密封及性能认证 |
| 独立后加工与寿命预测 | 本轮不纳入热熔植入、焊接、胶粘、喷涂、电镀、印刷、激光标记，也不预测模具／排气系统的寿命 |

同一特征可以服务不同检查，但本台账只保留制造目标。例如，卡扣根部保留成型厚度、圆角和脱模检查，不检查装配扣合力；孔径公差保留注塑过程能否达到该公差的检查，不判断它与配合件是否装得上。壁厚均匀也不能替代拔模、进胶、排气和顶出等检查。

## 使用口径

- 来源编号如 01.09 不是 check_id；146 行不是 146 个独立算法。同一业务可有多个来源行，不能因此重复测量或重复计问题。
- 先按上述范围确认是否属于注塑 DFM，再判断覆盖路径。A/B/C/D 表示方案路径和输入边界，不代表需求领域、严重程度或当前完成状态。实际可执行范围由已发布规则、能力和本次输入决定。
- 原清单中的经验数值是工程需求资料，不写死进程序，不覆盖已发布规则；实际阈值、适用条件及公式以审核后的 Rule Version 为准。
- 启动时登记模型、工艺和单位；预览可先显示，单轮正式识别在主方向确认后启动。结构（含倒扣范围内结构）、属性、倒扣面、滑块／斜顶成型面与退出方向候选统一入快照，并在 Worker 内部派生按 face ID 查询的面归属索引；Hermes 接收公开语义记录，不接收该索引。按三类组确认，不再固定安排倒扣二次识别；不确定的方案／方向留待用户选择或补充。厚度、尺寸等方向无关任务按自身依赖推进；材料等业务 Fact 按适用规则补充。
- Boss 按几何结构区分实心和带孔；带孔 Boss 柱对应 `hollow_boss`，不以螺钉用途作为识别或柱壁规则匹配前提。原来源编号保留，条目显示名称按当前结构分类规范化。
- 产品用途、外观、纹理及工程对象需可靠来源和用户确认；型芯／型腔侧候选不是实际模具实体。物理仿真和试模结论不能由几何预筛替代。
- 具体运行顺序见[主流程](dfm-main-workflow-explained.md)，会话、coverage 和依赖处理见[会话设计](dfm-geometric-session-contract.md)；本台账不重复定义协议。

## 覆盖分类

| 路径 | 来源行数 | 能判断到什么程度 | 必须补齐什么 |
| --- | --- | --- | --- |
| A 主流程可判 | 42 | 产品结构、几何量与明确规则 | 对应算法、必要属性、方向和对象确认 |
| B 补对象可判 | 54 | 补齐后继续使用几何与规则流程 | 模具／机构／工具、嵌件／包胶对象、标注及 PMI 等结构化对象 |
| C 仅预筛 | 37 | 几何风险代理量可判规则，不代表物理结果 | 仿真、工艺验证或试模依据 |
| D 数据／审核支路 | 13 | 资料、生产／检验事实和工程审核 | 受控 Fact 与证据；需要时复用几何量 |

表中数量按每行的主路径统计；一个制造议题仍可依赖其他路径。例如，D 类尺寸制造能力检查可复用 A 类壁厚，但尺寸能力仍须有经验证的过程数据。几何预筛与仿真／实测验证应分别记录覆盖程度，不能将缺少工艺依据的预筛提升为制造合格结论。

## 计算口径与责任边界

厚度需对向面、材料内有效路径和明确采样口径，不能直接取所有面的最短距离；模具机构及工具的净距需区分允许接触和运动干涉。筋／柱的参考厚度是局部关联主壁，不是全件平均值。拔模必须使用对应成型方向及统一符号，负角本身不等于真实倒扣。深径比区分有效成型段、锥底和阶梯段；钢料分析先明确模具材料域。极值和未检出结论要附覆盖与精度限制。
